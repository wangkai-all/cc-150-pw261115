# 学业检查 · 学分审计

零依赖（仅 Node.js 内置模块）的学业审计应用：导入培养方案、课程等价关系与学生成绩，按入学年份选择适用方案，审计必修、选修组与总学分完成情况，并解释每一个学分缺口。

## 运行

```bash
npm start          # http://localhost:3000 ，启动后自动载入内置样本
npm test           # node:test 引擎测试（27 个用例）
```

## 目录结构

```
data/                  虚构样本（带规则版本号）
  catalog.json         课程库（CAT-2026.1）
  programs.json        培养方案 2018版 / 2022版（PROG-2026.1）
  equivalences.json    课程等价关系（EQ-2026.1），限定方案与入学年份
  prerequisites.json   先修要求（PRQ-2026.1）
  prerequisites-issue.json  故意含成环与缺失引用的问题样本
  students.json        4 名虚构学生（STU-2026.1）
src/                   纯 ESM 规则引擎，浏览器与 Node 共用同一套代码
  terms.js             学期解析与排序
  grading.js           重修（max / last）、补考（封顶）成绩折叠
  equivalences.js      等价关系的适用范围解析与拒绝原因
  prerequisites.js     先修成环/缺失检查 + 修读时序检查（支持等价视同通过）
  audit.js             必修抵扣、选修组回溯互斥分配、总学分去重核算、缺口原因
  data-loader.js       导入归一化与结构校验
  export.js            JSON / CSV 导出（保留规则版本与分配依据）
test/                  node:test 测试
web/                   前端页面（原生 HTML/CSS/ES Module，无构建步骤）
server.js              静态服务 + 样本 API
```

## 核心规则

### 1. 按入学年份选方案
每个方案声明 `effectiveEnrollYears`，学生只匹配自己入学年份覆盖的版本；找不到适用版本时回退并显式告警，不会静默套用。

### 2. 重修、补考
- 2018 版 `scoreRule: max`：重修取历次最高分；2022 版 `last`：按最近一次成绩计。
- 补考通过按方案 `makeupPolicy.cap`（60）封顶，即使卷面更高。

### 3. 等价关系的作用域
等价关系同时限定**方案版本**与**入学年份**。例如 2022 版的 `CS110→CS101` 不能用于 2019 届学生；不适用时在缺口原因与问题面板中给出明确拒绝理由，而不是静默忽略。

### 4. 互斥抵扣（一门课只算一次）
- 必修直修与等价替代占用同一门实修课程后，选修组不能再次使用。
- 选修组采用**回溯分配**：课程可同时属于多个组时，引擎求出一套完整、互斥的分配方案（按候选稀缺度排序 + 学分门槛枚举），绝不按组分别统计后重复计学分。
- 结构性无解的组保留为空并报缺口，其余组仍给出最优分配。
- 总学分按方案域内通过课程的**去重集合**核算；方案外 / 课程库不存在的课程不计入毕业学分，但单独列出原因。

### 5. 先修检查（问题优先上报）
- 先报先修图本身的问题：成环（DFS 三色检测）、课程信息缺失。
- 图健康时才做修读时序检查：先修必须在**更早学期**通过；同学期通过不算。等价源课程通过视同通过目标先修。

### 6. 试选（不污染正式成绩）
页面可加入下一学期试选课程，引擎在成绩副本上重新审计，展示新增学分、新补上的要求与仍未满足的条件。试选数据不写回 `students`，重置或切换学生即消失。

### 7. 导出
- JSON：含每个数据域的规则版本号、每名学生的必修/选修分配与依据（basis）、被拒绝的等价关系、先修检查结果。
- CSV：逐要求 + 总学分行，含缺口原因文本（带 BOM，Excel 直接打开不乱码）。

## 导入格式

页面接受 JSON 文件，支持两种形态，可多文件合并导入（按数据域替换）：

```json
// 包装对象（推荐，带版本号）
{ "version": "PROG-2026.1", "programs": [ ... ] }
// 裸数组（按文件名识别数据域）
[ { "id": "CS101", "name": "程序设计基础", "credits": 4 } ]
```

数据域键：`catalog` / `programs` / `equivalences` / `prerequisites` / `students`。
